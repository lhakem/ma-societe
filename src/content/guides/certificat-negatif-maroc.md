Le certificat négatif est le premier document de toute création de société au Maroc. Sans lui, impossible de rédiger les statuts ni d'immatriculer la société. Voici comment il fonctionne et comment choisir un nom qui a toutes les chances d'être accepté du premier coup.

## Qu'est-ce que le certificat négatif ?

Le certificat négatif est délivré par l'**OMPIC**, l'Office marocain de la propriété industrielle et commerciale, qui tient le registre central du commerce. Il atteste qu'aucune autre entreprise n'utilise déjà la dénomination, l'enseigne ou le nom commercial que vous souhaitez.

Il est dit « négatif » parce qu'il certifie l'**absence** d'antériorité : le nom est libre, vous pouvez l'utiliser.

## Comment faire la demande

La demande se fait en ligne auprès de l'OMPIC. Vous indiquez :

- la ou les dénominations souhaitées, par ordre de préférence ;
- la forme juridique de la société (SARL, SARL AU, SA, SAS…) ;
- l'activité principale ;
- l'identité du demandeur.

Si le nom est disponible, le certificat est délivré rapidement. Il est ensuite joint au dossier de création. Le certificat a une durée de validité limitée : ne le demandez pas des mois avant de lancer réellement la création.

## Les règles pour choisir un nom accepté

L'OMPIC peut refuser un nom pour plusieurs raisons. Pour mettre toutes les chances de votre côté :

- **Évitez les noms trop proches** d'une société existante : un nom identique ou presque identique, même avec une orthographe différente, sera refusé ;
- **Évitez les termes génériques seuls** comme « Services », « Commerce » ou « Consulting » : associez-les à un nom distinctif ;
- **Vérifiez les marques déposées** : un nom libre comme dénomination peut être protégé comme marque, ce qui vous exposerait à un litige ;
- **Évitez les termes réglementés** comme « banque », « assurance » ou « bourse », qui supposent des autorisations particulières ;
- **Proposez au moins trois noms** pour éviter de relancer la procédure.

## Dénomination, enseigne, nom commercial : quelle différence ?

- La **dénomination sociale** est le nom juridique de la société, celui des statuts et du registre du commerce ;
- Le **nom commercial** est celui sous lequel vous exploitez votre fonds de commerce ;
- L'**enseigne** est le nom affiché sur votre local.

Dans la plupart des créations, seule la dénomination sociale est demandée. Si vous comptez exploiter un nom différent auprès du public, mentionnez-le dans la demande.

## Les erreurs fréquentes

1. **Choisir un nom sans vérifier les marques.** Le certificat négatif ne vous protège pas contre le titulaire d'une marque déposée.
2. **Demander le certificat trop tôt.** S'il expire avant la fin de la création, il faut recommencer.
3. **Ne proposer qu'un seul nom.** Un refus fait perdre plusieurs jours.
4. **Réserver un nom trop restrictif.** « Casa Plomberie » sera gênant si vous développez une activité de climatisation à Rabat.
